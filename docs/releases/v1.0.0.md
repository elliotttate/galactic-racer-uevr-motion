Initial public release of Galactic Racer UEVR motion telemetry.

- Native x64 UEVR plugin with reflected vehicle physics sampling.
- SimHub UDPConnector JSON on port 20777 and native External Sim integration on 20778.
- SimTools v3 generic UDP on port 4123 and versioned Windows shared memory.
- Configurable rates, acceleration filtering, motion limits, and axis signs.
- Neutral output during menus, pause, invalid state, and physics discontinuities.
- Source, build scripts, installer, telemetry listener, tests, and validation summaries included.

Download and extract the ZIP, exit the game, then run `Install.ps1` in PowerShell.
Launch with UEVR injected. In SimHub, enable **STAR WARS Galactic Racer (UEVR)**.
SimHub's native External Sim route requires 9.11.5 or later; the UEVR backend
must expose plugin API 2.34.0 or later.

Release build and automated motion tests passed. Live game captures verified
JSON, SimTools, shared memory, pause neutralization, and the 188-byte SimHub
packet layout. A physical motion rig and full SimHub UI session were not tested.
